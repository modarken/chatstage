# Security policy

## Supported versions

Security fixes go into the latest release. ChatStage targets the latest .NET only.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/modarken/chatstage/security/advisories/new).

Include what an attacker can do, how to reproduce it, and the version affected. You'll get an answer within a week.

Issues in ChatStage's approval binding (a client making a tool run that the agent didn't ask about, or with
different arguments) are security issues: please report them this way.
